# Site Cormier-Jomphe

Site généalogique familial. Publié via GitHub Pages depuis le dossier `/docs` de la branche `main`.

## Fichiers

- `index.html` — la page complète (arbre, carte, chronologie, fiches)
- `family-data.js` — toutes les données généalogiques (naissances, mariages, décès, lieux, sources)
- `carte-atlantique.html` — la carte des migrations
- `support.js` — moteur d'affichage
- `.nojekyll` — empêche GitHub de reformater les fichiers

## Mettre le site à jour

Toute correction généalogique se fait dans `family-data.js`, puis on remplace le fichier dans le dépôt.

## Activer la publication

Dépôt → Settings → Pages → Source: *Deploy from a branch* → Branch: `main`, dossier `/docs` → Save.
L'adresse sera `https://melco007.github.io/Site_Cormier_Jomphe/`.
